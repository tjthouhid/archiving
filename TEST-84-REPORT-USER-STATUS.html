TEST-84 — User status in reports

Reports and DNA scores can include inactive, archived, or deleted people. Those reports start on Active. Archived and deleted names are shown as Anonymised.

All guides · Jira TEST-84

What changed

Custom reports for users, registrations, certificates, and DNA scores have a User status filter: All, Active, Inactive, Archived, and Deleted. A new report starts on Active. Choose the other statuses, or All, to include people the organisation list no longer shows.

Each of those reports can show a User status column. For Archived and Deleted, the name and email columns say Anonymised. Inactive people keep their name.

The users dashboard chart “Users by status” uses the same four stages. A saved report that still says Left is treated as Inactive.
