TEST-95 — Add user page refresh

After an organisation owner creates a user, the add-user page returns to a blank form and still shows the success message.

All guides · Jira TEST-95

What changed

Creating a user at /users/add used to leave the name, email, and role filled in. A successful create now clears those fields, custom fields, and classifications, and leaves the green success message in place. Editing an existing user does not clear the form.

Checks

Sign in as an organisation owner. Open /users/add.
