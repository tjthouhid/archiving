TEST-100 — Linked account emails

Organisation and IW admin views keep a linked organisation email visible and searchable.

All guides · Jira TEST-100

What changed

When a learner’s organisation email is stored on a linked account, that organisation’s user list shows the email instead of a dash. The IW admin user list includes that linked organisation email, and searching for it finds the learner.

An organisation still does not see another organisation’s email. An archived organisation email stays off the active IW list.
