TEST-59 — Data sharing stays in the learner portal

Data sharing is a learner’s choice. It is not an organisation System menu item. Shared workspaces are not part of this change.

All guides · Jira TEST-59

What changed

The System menu no longer lists Data sharing permissions for an organisation user. A learner, or someone with no live organisation, still opens it at /system/data-sharing. An organisation user who opens that address is refused.
