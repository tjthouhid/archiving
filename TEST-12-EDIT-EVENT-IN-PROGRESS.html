TEST-12 — Edit an event that is in progress

An event can still be edited, and a seat can still be changed, after it has started. It locks once it has finished.

All guides · Jira TEST-12

What changed

The event edit page and the event list no longer lock an event just because the start time has passed. Edit stays available while the event is in progress. It locks when the event status is completed, or when the end time has passed. A booking can be removed until then, so a seat can be given to someone else on the day. Trainers still cannot be changed after the event or a session has started.
