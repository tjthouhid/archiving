Link account password

Linking another account asks for one new password, and that password signs in every linked account.

All guides

What changed

On /settings/security, verifying an email that already belongs to another account opens a password dialog. The dialog has no close button. Escape and a click outside do not dismiss it. The warning explains that the accounts stay separate, this password replaces the password on every linked account, and each of those emails can then be used to sign in.
