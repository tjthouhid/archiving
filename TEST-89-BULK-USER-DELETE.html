TEST-89 — Bulk user delete

An IW admin can delete more than one user, and those people show on the Deleted tab. An organisation owner can delete one user at a time.

All guides · Jira TEST-89

What changed

On the IW admin user list, Delete Selected uses the same form as deleting one user. A reason is required, and the people are erased. They appear on the Deleted tab, not the Archived tab.

On the organisation user list, Delete Selected is gone. The row menu can still delete one user, and that form still asks for a reason.
